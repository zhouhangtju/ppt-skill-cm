# 报告类型：`technical_research`

本文件定义技术研究类演示文稿的默认章节框架、提取重点、推荐页面范式映射与页级判断语法。

它不重复视觉基线，也不重复标准执行步骤。

## 适用场景

- 技术研究
- 模型分析
- 能力研究
- 架构研究
- 竞品 / 竞对分析
- 趋势分析
- 技术应用与落地分析

## 默认章节框架

除非用户提供了更强的大纲，否则使用以下框架：

1. 概述与简介
2. 背景与发展
3. 原理与架构
4. 能力特点分析
5. 竞争力分析
6. 应用与落地
7. 总结与建议

## 各章必须回答什么

### 1. 概述与简介

- 研究对象是什么
- 为什么要研究它
- 本报告将从哪些角度展开

### 2. 背景与发展

- 技术从哪里来
- 当前发展到了什么阶段
- 为什么现在值得重点关注

### 3. 原理与架构

- 核心工作机制是什么
- 架构由哪些关键部分组成
- 技术链路如何闭合

### 4. 能力特点分析

- 主要能力有哪些
- 与传统方案相比，有哪些明显变化
- 适配哪些任务与场景

### 5. 竞争力分析

- 相比主要替代方案，优劣势分别是什么
- 差异化在哪里
- 约束和风险在哪里

### 6. 应用与落地

- 技术怎样转化为实际价值
- 主要应用场景与落地路径是什么
- 哪些条件支持落地，哪些条件仍不具备

### 7. 总结与建议

- 总判断是什么
- 值得做 / 不值得做的边界是什么
- 后续关注与行动建议是什么

## 提取重点

优先提取：

- 技术原理
- 架构层次
- 能力特征
- 差异化对比
- 应用案例
- 落地路径
- 风险与限制
- 总结性判断

## 推荐页面范式

- 背景与趋势：研究证据拼接页
- 原理与架构：架构演进横排 + 解释模块
- 能力分析：指标 / 卡片 / 对比模块
- 竞争力分析：对比表 + 结论侧栏
- 应用与落地：观察条 + 案例网格 + 判断条，或价值链 + 商业化路径
- 总结与建议：总结卡片 + 建议网格

## 页级判断语言

优先让页面收口到以下判断方式之一：

- 核心结论
- 主要差异
- 关键价值
- 最适配场景
- 主要落地障碍
- 当前成熟度判断

## 需要避免的弱表达

不要把整份演示文稿降成：

- 技术百科式罗列
- 功能清单
- 行业标签堆砌
- 只有描述、没有判断的研究稿
