# 报告类型：`project_construction`

本文件定义项目建设类演示文稿的默认章节框架、提取重点、推荐页面范式映射与页级判断语法。

它不重复视觉基线，也不重复标准执行步骤。

## 适用场景

- 项目立项
- 建设方案汇报
- 可研 / 可行性分析
- 投资测算
- 决策上会
- 重大项目建设论证

## 默认章节框架

除非用户提供了更强的大纲，否则使用以下框架：

1. 项目背景与建设必要性
2. 建设目标与建设范围
3. 总体思路与建设方案
4. 实施路径与进度安排
5. 投资估算与资金安排
6. 项目组织与管理机制
7. 预期成效与风险保障
8. 决策事项

## 各章必须回答什么

### 1. 项目背景与建设必要性

- 为什么要建
- 当前问题或机会在哪里
- 不建设会带来什么影响

### 2. 建设目标与建设范围

- 项目要达到什么目标
- 覆盖哪些对象、系统或范围
- 哪些内容明确纳入，哪些不纳入

### 3. 总体思路与建设方案

- 建设总体逻辑是什么
- 技术 / 业务 / 组织方案如何构成
- 关键模块如何协同

### 4. 实施路径与进度安排

- 采用什么分阶段实施路线
- 关键里程碑如何设置
- 时间安排与依赖关系是什么

### 5. 投资估算与资金安排

- 投资规模是多少
- 主要成本由哪些项构成
- 资金安排与分期投入如何设计

### 6. 项目组织与管理机制

- 谁来负责
- 治理、协调与决策机制如何运转
- 项目如何保证推进闭环

### 7. 预期成效与风险保障

- 项目建成后带来什么结果
- 风险点有哪些
- 有哪些保障措施

### 8. 决策事项

- 需要会上拍板什么
- 推荐结论是什么
- 还需协调什么

## 提取重点

优先提取：

- 建设背景
- 问题与必要性证据
- 目标与范围
- 总体方案
- 实施路径
- 投资与预算
- 组织治理
- 风险与保障
- 决策事项

## 推荐页面范式

对于背景与必要性：

- 指标簇 + 支撑模块
- 研究证据拼接页

对于目标与范围：

- 多卡片矩阵
- 范围拆解页

对于总体方案：

- 架构演进横排 + 解释模块
- 方案模块图 + 说明块

对于实施路径：

- 时间线 + 状态条
- 路线图页

对于投资与资金：

- 对比表 + 结论侧栏
- 指标页 + 解释模块

对于组织与治理：

- 组织图 + 职责模块
- 流程 / 机制页

对于成效与风险：

- 总结卡片 + 风险保障模块

对于决策事项：

- 对比表 + 判断框
- 建议卡片 + 决策清单

## 页级判断语言

建设类页面应优先强调：

- 为什么必须建
- 应该怎么建
- 这样建的价值是什么
- 风险在哪里
- 需要怎么决策

## 需要避免的弱表达

不要把整份演示文稿降成：

- 纯流程介绍
- 纯架构图堆砌
- 只有计划、没有决策判断
- 只有预算数字、没有投入逻辑
