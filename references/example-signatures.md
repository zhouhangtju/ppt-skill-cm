# Example Signatures

This file records reusable style signatures extracted from high-quality reference decks.

## Use

Read this file when:
- the user provides reference decks or screenshots
- deciding what "good" looks like for a page type
- translating a deck sample into reusable page choices

Treat these signatures as stronger than the generic default style.

## Signature A: DeepSeek handwritten research deck

Observed from a high-quality handwritten technical research deck.

### Visual character

- strong blue headline
- frequent red inline emphasis
- higher-density information packing
- visible evidence-driven storytelling
- pages often include screenshots, proof blocks, or page-level judgments
- chapter page uses a designed navigation device rather than a plain list

### Typical page grammar

- conclusion title first, not neutral title first
- lead sentence directly under title
- evidence blocks arranged in a rich mosaic
- card matrices often vary in importance instead of remaining perfectly equal
- application page often uses:
  - observation bar
  - 4-6 industry / case cards
  - bottom judgment strip

### Best-fit use cases

- industry impact pages
- progress / event / public reaction pages
- application landing pages
- competition and market effect pages

### What to preserve if this is the user's reference

- strong narrative rhythm
- non-flat card hierarchy
- explicit observation / judgment devices
- case-level granularity

### What not to do

- do not flatten it into 4 large identical white boxes
- do not remove page-level judgment strips
- do not replace evidence mosaics with generic summary cards

## Signature B: Manus Qwen modular clean template

Observed from a clean generated research deck with reusable modular pages.

### Visual character

- blue-white minimalist system
- left title bar or subtle title marker
- clean, well-aligned modules
- stable page rhythm
- consistent geometry and spacing
- modular cards, metric blocks, comparison sections, and evolution rows

### Typical page grammar

- title with a left-side accent device
- lead sentence beneath title
- 2-column module structure
- metric chips or metric boxes in overview pages
- architecture pages often use a top evolution row plus 2-4 explanation modules
- chapter page often uses a simple but clean list emphasis system

### Best-fit use cases

- overview pages
- architecture evolution pages
- capability summary pages
- comparison pages
- clean chapter navigation

### What to preserve if this is the user's reference

- alignment discipline
- module consistency
- restrained palette
- reusable layout rhythm

### What not to do

- do not inject random decorative motifs that break the modular system
- do not simplify too far into a blank generic page
- do not lose the title / lead / module rhythm

## Hybrid Guidance

When both signatures are relevant:
- use Manus-style modular structure as the geometric baseline
- use DeepSeek-style observation bar, judgment strip, and stronger narrative emphasis where the content is case-heavy or impact-heavy

This hybrid mode is especially suitable for:
- technical research decks that need both clean structure and stronger storytelling
